### Download
**[Edge.dmg](https://github.com/thebitanpaul/Edge/releases/latest/download/Edge.dmg)** — universal (Apple silicon + Intel), macOS 13 Ventura or later.

### Install — on both Macs
1. Open `Edge.dmg` and drag **Edge** into **Applications**.
2. Open Edge.
3. If macOS blocks it, click **Done**.
4. Go to **System Settings ▸ Privacy & Security**.
5. Under **Security**, click **Open Anyway**.

macOS asks this only once: Edge is open source, but not notarised by Apple. Then grant Accessibility (both Macs) and Input Monitoring (the primary), and choose **Set up** on both.
