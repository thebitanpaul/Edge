## Edge 1.0.0 — first public release

One keyboard and mouse across two Macs, even when they can't share an Apple ID.

### What's in it
- Seamless pointer and keyboard crossing between two Macs
- One-tap pairing with a six-digit confirmation, no account
- End-to-end encrypted links (TLS, ECDHE-PSK, ChaCha20-Poly1305)
- Drag files across the edge · shared clipboard (opt-in) · media keys follow you
- Thunderbolt / USB-C cable support, multi-display arrangement
- Menu bar app with Control Center controls on macOS 26+
- Swap roles on both Macs at once · auto-reconnect · start at login
